Вопросы

Частые вопросы: ии-консультант

ИИ не наговорит лишнего?

Он отвечает только по вашей базе знаний. Если ответа в базе нет или клиент просит человека, диалог уходит вам. Перед запуском прогоняю тестовые вопросы.

Какую нейросеть используете?

По умолчанию YandexGPT: работает из России без VPN, данные остаются в российской инфраструктуре. По задаче можно подключить и другие модели.

Можно подключить к Авито?

Да, через официальный API мессенджера Авито. Для этого нужен тариф Авито с доступом к API — проверим это до начала работ.

Сколько стоят запросы к нейросети?

Оплачиваются по факту использования, для малого бизнеса это обычно небольшие суммы. Точнее посчитаю по вашему потоку обращений.

Сколько стоит?

Первый этап — от 30 000 ₽: консультант по базе знаний и заявки в Telegram. Сопровождение — от 3 000 ₽ в месяц.
